# 数据展示、数字日期字段和故障恢复

Refs #1，基线 develop `4215dd9c80ef3346838c58eb8e1b74ea831f2d00`。按已确认顺序先实现功能，真实业务数据在部署后验收；本地不运行测试、静态检查或构建。本批补齐原设计组件矩阵中的图表、指标、数字与日期输入，复用现有快照、Form、权限和同会话动作，不增加业务操作或配置。

## 数据组件

`DataChart(data_ref, category, series, kind?)` 支持柱状、折线和占比图，最多三个数值系列，占比图只允许一个非负系列。底层使用兼容 React 18 的 Recharts 3.10.1；数据从现有授权 DisplayTable 读取，模型仅选择数据引用、列和图形。服务端描述符只补充可用分类列和数值列的键，不向布局模型复制原始单元格。

列标题提供名称及已知单位，不猜测单位、不换算、不聚合或填补数据；文本数字与超大整数文本不会强转为数值。空值是缺口，不补零。分类和系列必须来自白名单列，非法列或类型显示不可用并保留可读回答。空结果、全空值或占比全零显示空态。保持快照行顺序和最多五十行限制，显示捕获时间及已捕获/总行数，不将局部快照宣称为数据库全局统计。占比图图例在固定图形区域外换行，避免大量分类挤占图形。

`MetricValue(data_ref, field)` 只展示未截断的单条工具结果中的数值字段，支持零值和空态；即使只捕获了一行，只要总行数大于一也不能作为单值指标。需要总量或均值时由已有工具先计算并返回单条结果，不在展示层选择任意记录或对截断数据求和。图表和指标沿用受控替代原文规则；未知引用或无效字段不能折叠原始答案。需要精确表格或记录动作时可同时组合已有 DataTable，不新增另一套点击执行协议。

## 表单字段

Form 的 `type` 增加 `number`、`date`。数字可使用明确的 `min`、`max`；未提供时允许有限数值，包括小数和负数，不推测业务范围。日期使用实际有效的 `YYYY-MM-DD` 日历日期。前后端同时校验类型、范围、闰日及初始值；拒绝非有限数值、十六进制等非十进制输入、无效日期和错误的边界定义。

字段值沿用字符串合同，不把 `1.250` 改成 `1.25`，不把日期转换为时间戳或时区日期。必填、可选、条件显隐、保存许可、草稿冲突、修改回填与整表提交均走已有链路；数字和日期不产生新的工具权限。修改问卷时保留字段类型和已明确的边界。

## 故障恢复约定

沿用现有“原生答案先落盘、UI 快照先持久化再发送、刷新和重连读取权威快照”的恢复路径，不增加第二套事件队列。UI 存储失败保留原生可读答案，不自动重新执行 Agent 或工具；完整快照提交后发送失败，可重新订阅读回完整视图。启动时将遗留 streaming 标记为 failed，并记录 `UI_STREAM_INTERRUPTED`，不会自动重放生成或业务动作。

恢复订阅和每个动作入口核对同一原生会话代次中的答案锚点；历史回滚后失去答案锚点的孤立视图会被移除，旧动作会被拒绝，已有动作准入记录继续保留。锚点由原生 SessionState 的只读投影查询，不复制答案正文，不改变原生数据库结构。测试注入 UI 存储失败、提交后发送中断、原生历史与 sidecar 不一致和重启情形，验证可读回答、快照恢复及不重放契约。

UI 数据库版本超出支持范围时，仅禁用本次运行的交互视图，明确记录版本错误，普通聊天仍可使用；不降级改写或删除未来版本数据。恢复交互需要使用支持该数据库版本的安装。进程重启后不会保存或猜测旧视图的模型凭据，已有完整视图可恢复，旧模型生成重试仍明确返回 `UI_MODEL_UNAVAILABLE`。这不是跨数据库事务或任意业务工具的 exactly-once 承诺。

业务 MCP 工具及其字段绑定、真实照明数据和生产模型效果留待部署后验收；不以夹具数据替代真实业务完成判据，不关闭 Issue #1。
