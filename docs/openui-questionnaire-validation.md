# 真实模型组合问卷验收

Refs #1，对应 AT05、AT06、AT13 的问卷路径，基线为 develop 的 bdd64eaf167c137957e3dff57b2eb35469efee68。现有 Form 已支持单选、多选、条件字段、显式允许的草稿与同会话提交，本批先验证真实模型能否正确组合和使用这些能力，不新增组件、业务工具、配置、协议或存储结构。

复用 opt-in 真实模型浏览器验收和隔离 Gateway，以明确允许保存的虚构公开项目资料生成一份五字段问卷。核对字段与选项、问卷单独替代静态原文、条件字段隐藏时清除旧值、重新显示时必填、已允许的草稿刷新恢复，以及桌面和手机展示。填写和刷新不应增加模型或工具调用。

随后双击提交，检查只发送一个带原表单身份的新用户回合，提交内容包含全部可见答案且不含已撤回字段。真实 Agent 应复述所填信息并生成修改/确认选项；刷新已提交问卷不自动重发，点击确认继续原会话。测试使用现有 Provider 和组件，实际行为以 GitHub Actions 的确切提交、日志、截图及摘要为准，本地不运行测试、静态检查或构建。

该样本不涉及个人敏感问卷资料、外部 MCP、业务写操作或照明业务。既有固定响应问卷用例继续覆盖个人答案不保存等路径，单个真实模型样本不代表全部模型与措辞都可靠，不据此关闭 Issue #1。

## 提交后的修改与再次确认

本批从 develop 的 e2da9b3f7d940044234856d46a2e5a149f50d3e1 继续，只补现有问卷的修改路径。原提交仍锁定；修改按钮在原会话请求一份新问卷。现有交互入口向 Agent 传递条件规则：如果用户要求修订问卷，保留原字段、选项和条件，并在公开回答中列出明确允许保留的已有答案；其余交互仍按原请求处理。UI Generator 据此生成新 Form，不识别固定按钮名、不解锁或覆盖原卡片，也不自动重新提交。

现有字段增加可选 initial，类型及长度沿用表单答案约束；仅 persist:true 的字段允许提供初值，前后端均校验答案类型、选项和重复选择。流式预览期间不可编辑，完成后按完整定义初始化；已保存草稿（包括用户清空的值）优先，之后不再重复应用初值。隐藏条件字段在初始化时清空，之后重新显示不会复活旧初值。新问卷默认空白，个人敏感答案不回填，不能用 initial 猜测用户答案。没有增加组件、配置、数据库结构、模型调用阶段或通用流程引擎。

修改了组件签名及源码，因此按既有流程在 GitHub Actions 生成并审查新清单。旧 library_hash 的历史卡片沿用原有可读原文降级，不宣称跨清单恢复交互。验收复用上一批真实模型问卷，增加点击修改、回填、条件变更、再次提交、刷新恢复与最终确认；初次提交和修订提交使用不同的 block/request 身份。具体 GitHub 执行结果、失败证据和部署版本记录于本批 PR。
