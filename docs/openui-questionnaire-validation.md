# 真实模型组合问卷验收

Refs #1，对应 AT05、AT06、AT13 的问卷路径，基线为 develop 的 bdd64eaf167c137957e3dff57b2eb35469efee68。现有 Form 已支持单选、多选、条件字段、显式允许的草稿与同会话提交，本批先验证真实模型能否正确组合和使用这些能力，不新增组件、业务工具、配置、协议或存储结构。

复用 opt-in 真实模型浏览器验收和隔离 Gateway，以明确允许保存的虚构公开项目资料生成一份五字段问卷。核对字段与选项、问卷单独替代静态原文、条件字段隐藏时清除旧值、重新显示时必填、已允许的草稿刷新恢复，以及桌面和手机展示。填写和刷新不应增加模型或工具调用。

随后双击提交，检查只发送一个带原表单身份的新用户回合，提交内容包含全部可见答案且不含已撤回字段。真实 Agent 应复述所填信息并生成修改/确认选项；刷新已提交问卷不自动重发，点击确认继续原会话。测试使用现有 Provider 和组件，实际行为以 GitHub Actions 的确切提交、日志、截图及摘要为准，本地不运行测试、静态检查或构建。

该样本不涉及个人敏感问卷资料、外部 MCP、业务写操作或照明业务。既有固定响应问卷用例继续覆盖个人答案不保存等路径，单个真实模型样本不代表全部模型与措辞都可靠，不据此关闭 Issue #1。
